# 查询韩国股市

## 执行

1. 先确定查询时间：
   - 用户没说时间：固定用北京时间 `09:00`。
   - 用户明确说北京时间：照用户给的 `HH:MM`。
   - 用户说「现在」「截至现在」：使用 `now`，脚本会取Naver与Yahoo最新共同确认的分钟；Yahoo可能延迟，回复必须照JSON写出实际分钟。
   - 本技能只查当天韩国交易日的分钟截面；用户问历史日期时，直接说明暂不支持，不要拿今天数据冒充。

2. 用 Shell 运行：

   ```sh
   python "$ASSISTANT_SKILLS_DIR/check-korea-market/scripts/query_korea_market.py" --time 09:00
   ```

   明确时间时替换 `09:00`；查询现在则用 `--time now`。不要自行改数据源或手算。

3. 读取脚本JSON：
   - `status=OK` 才能报告数字和红绿结论。
   - `status=ABSTAIN` 时只报告 `errors` 中的具体原因，不得用单一来源硬判。
   - `indices` 里的 `snapshot_change_pct` 是指定时刻相对前一韩国交易日收盘的涨跌幅。
   - `snapshot_both_red` 是指定时刻KOSPI/KOSDAQ是否同时高于前收。
   - `opening_double_red` 是北京时间08:00正式开盘缺口是否同时大于0。
   - 这两个“双红”口径不同，必须分别命名，绝不混写。

## 回复格式

默认简洁回复：

```text
韩国股市（北京时间2026-08-13 09:00，双源已核对）
KOSPI：6,825.37，较前收 +3.74%；开盘缺口 +2.96%
KOSDAQ：870.91，较前收 +1.40%；开盘缺口 +0.49%
09:00截面：双红
08:00正式开盘：双红
```

所有点位保留两位小数、百分比保留三位。首行必须写明实际查询的北京时间。若用户只问大盘情况，不主动给买卖建议。

## 硬性规则

- 没说时间就查北京时间09:00，即使提问发生在其他时刻也不改成「现在」。
- 查询「现在」时不得声称实时；首行写脚本返回的实际北京时间，若有 `latest_common_delay_minutes` 就说明滞后分钟数。
- 脚本用Naver与Yahoo同一分钟交叉核对；任一来源缺失、日期陈旧、前收/开盘/截面方向冲突，统一弃权。
- 不编数字，不用网页搜索摘要代替脚本结果，不把盘中涨跌叫作开盘缺口。
- 数据仅用于行情查询；除非用户明确追问，否则不把双红直接解释成买入或卖出信号。
